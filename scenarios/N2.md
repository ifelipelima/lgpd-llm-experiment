# N2 - Necessidade / Situação aparentemente adequada

## Contexto

Uma plataforma de recrutamento permite que candidatos criem um perfil profissional e recebam recomendações de vagas compatíveis.

## Funcionalidade

O sistema utiliza as informações do perfil para recomendar oportunidades e permitir candidaturas.

## Dados envolvidos

Nome, contato, formação acadêmica, experiência profissional, competências e localização aproximada.

## Comportamento/regra

As informações profissionais são utilizadas para identificar vagas compatíveis. A localização aproximada é usada para priorizar oportunidades próximas.

## Informação ao usuário

A plataforma informa quais dados são utilizados na recomendação de vagas e permite que o candidato escolha utilizar a localização para receber oportunidades próximas.

# N1 - Necessidade / Problema explícito

## Contexto

Uma plataforma de recrutamento permite que candidatos criem um perfil profissional e recebam recomendações de vagas compatíveis.

## Funcionalidade

O sistema utiliza as informações do perfil para recomendar oportunidades e permitir candidaturas.

## Dados envolvidos

Nome, contato, formação acadêmica, experiência profissional, competências, estado civil, número de filhos e renda familiar.

## Comportamento/regra

Todos os campos são obrigatórios para concluir o cadastro.

## Informação ao usuário

A plataforma informa que os dados são utilizados para conhecer melhor o perfil do candidato e oferecer oportunidades mais adequadas.

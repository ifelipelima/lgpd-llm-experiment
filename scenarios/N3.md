# N3 - Necessidade / Informação insuficiente

## Contexto

Uma plataforma de recrutamento permite que candidatos criem um perfil profissional e recebam recomendações de vagas compatíveis.

## Funcionalidade

O sistema utiliza as informações do perfil para recomendar oportunidades e permitir candidaturas.

## Dados envolvidos

Nome, contato, formação acadêmica, experiência profissional, competências e informações adicionais de perfil.

## Comportamento/regra

A plataforma informa que algumas informações adicionais podem ser utilizadas para melhorar as recomendações de vagas.

## Informação ao usuário

O usuário é informado de que esses dados adicionais ajudam a tornar as recomendações mais adequadas ao seu perfil, sem especificar como elas influenciam.

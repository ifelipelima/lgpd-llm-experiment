# F3 - Finalidade / Informação insuficiente

## Contexto

Aplicativo de corrida permite que usuários registrem suas atividades físicas.

## Funcionalidade

O aplicativo registra a localização do usuário durante uma corrida para calcular percurso, distância e velocidade.

## Dados envolvidos

Localização e histórico de atividades.

## Comportamento/regra

O histórico de localização também pode ser utilizado posteriormente para melhorar os serviços oferecidos pelo aplicativo.

## Informação ao usuário

O aplicativo informa que os dados poderão ser utilizados para melhorar seus serviços, mas não especifica quais usos posteriores podem ser realizados nem quais funcionalidades seriam beneficiadas.

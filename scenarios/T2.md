# T2 - Transparência / Situação aparentemente adequada

## Contexto

Um aplicativo de controle financeiro permite que usuários conectem suas contas bancárias para acompanhar gastos e organizar o orçamento pessoal.

## Funcionalidade

O sistema analisa as movimentações bancárias para categorizar despesas, gerar relatórios e enviar alertas sobre gastos.

## Dados envolvidos

Saldo, histórico de transações, estabelecimentos onde foram realizadas compras, valores e categorias de despesas.

## Comportamento/regra

Os dados são utilizados para gerar as funcionalidades financeiras apresentadas ao usuário. Caso o usuário opte por receber ofertas personalizadas, o aplicativo também utiliza categorias de consumo para selecionar promoções de parceiros.

## Informação ao usuário

Antes da conexão da conta, o aplicativo informa quais dados serão analisados, para quais funcionalidades serão utilizados, por quanto tempo serão mantidos e que a participação em ofertas personalizadas é opcional. Também informa que, ao ativar essa opção, categorias de consumo poderão ser utilizadas para selecionar ofertas de parceiros.

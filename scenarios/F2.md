# F2 - Finalidade / Situação aparentemente adequada

## Contexto

Aplicativo de corrida permite que usuários registrem suas atividades físicas.

## Funcionalidade

O aplicativo registra a localização do usuário durante uma corrida para calcular percurso, distância e velocidade.

## Dados envolvidos

Localização e histórico de atividades.

## Comportamento/regra

A localização é utilizada durante a atividade para calcular o percurso, a distância e a velocidade. Após a atividade, o histórico é mantido para que o próprio usuário possa consultar e comparar suas corridas anteriores.

## Informação ao usuário

Antes de iniciar o registro, o aplicativo informa que utilizará a localização para registrar a atividade e que o histórico das corridas ficará disponível para acompanhamento da evolução do usuário.
